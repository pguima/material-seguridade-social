# PARTE 2 — OS PARES QUE A BANCA QUER QUE VOCÊ CONFUNDA

## 2.1 🔴 80% × 100% (a média)

```
   ANTES da EC 103 ..... média dos 80% MAIORES salários de contribuição
   DEPOIS .............. média de 100% do período contributivo
   ONDE OS 80% AINDA VALEM ..... apenas no DIREITO ADQUIRIDO
```

## 2.2 🔴 20 anos × 15 anos (tempo mínimo)

```
   HOMEM filiado APÓS a EC 103 ......... 20 anos   ← única exceção
   Homem filiado ANTES (art. 18) ....... 15 anos
   Mulher (qualquer situação) .......... 15 anos
```

## 2.3 🔴 Incapacidade temporária × permanente

| | Temporária | Permanente |
|---|---|---|
| Incapacidade para | O trabalho **HABITUAL** | **QUALQUER** atividade que garanta subsistência |
| Duração | Temporária | Permanente + **insuscetível de reabilitação** |
| RMI | **91%** ⚠️ | 60%+2pp · **100%** se acidentária |
| Acréscimo de 25% | ❌ | ✅ se grande invalidez |

## 2.4 🔴 Auxílio-acidente × auxílio por incapacidade

| | Auxílio-acidente | Incapacidade temporária |
|---|---|---|
| Natureza | **Indenizatória** | Substitutiva |
| Efeito na capacidade | **REDUZ** | **IMPEDE** |
| Acumula com salário | ✅ | ❌ |
| Carência | **0** | 12 |
| Piso de 1 SM | ❌ | ✅ |
| Segurados | **Só E-D-A-Esp** | Todos |

## 2.5 🔴 Os dois rols restritos — não os troque

```
   AUXÍLIO-ACIDENTE .... empregado · DOMÉSTICO · avulso · especial
   SALÁRIO-FAMÍLIA ..... empregado · avulso        (SEM o doméstico!)
```
> **"O doméstico tem auxílio-acidente, mas não tem salário-família."**

## 2.6 🔴 Pensão por morte × auxílio-reclusão

| | Pensão por morte | Auxílio-reclusão |
|---|---|---|
| Carência | **NENHUMA** | **24** |
| Baixa renda | ❌ | ✅ (**do segurado**) |
| CF | art. 201, **V** | art. 201, **IV** |

## 2.7 🔴 Pedágio de 50% × pedágio de 100%

| | 50% (art. 17) | 100% (art. 20) |
|---|---|---|
| Idade mínima | **NENHUMA** | **57 (M) / 60 (H)** |
| Cálculo | Média × **fator previdenciário** | **100% da média** |
| Perfil | Rápido, vale menos | Lento, vale mais |

## 2.8 🔴 Pontos × idade progressiva (arts. 15 e 16)

```
   Ambas exigem 30 (M) / 35 (H) anos de contribuição.
   A diferença é o SEGUNDO requisito:
     art. 15 → PONTOS (idade + tempo)  ....... 86/96 → 100/105
     art. 16 → IDADE isolada ................. 56/61 → 62/65
```

## 2.9 🔴 Natimorto × aborto não criminoso

```
   NATIMORTO ................ 120 dias
   ABORTO NÃO CRIMINOSO ..... 2 SEMANAS ⚠️
```

## 2.10 🔴 14 anos × 21 anos

```
   SALÁRIO-FAMÍLIA ..... filho menor de 14 anos ou inválido
   DEPENDENTE .......... filho menor de 21 anos ou inválido/com deficiência
```

## 2.11 🔴 120 dias × 180 dias (salário-maternidade)

```
   BENEFÍCIO PREVIDENCIÁRIO ..... 120 dias, pago/apurado pelo INSS
   EMPRESA CIDADÃ ............... +60 dias, pagos pela EMPRESA
                                  (incentivo fiscal, adesão facultativa)
```

## 2.12 🔴 Aposentadoria rural × híbrida

```
   RURAL PURA ..... 60/55 anos + atividade rural no período imediatamente anterior
   HÍBRIDA ........ 65/60 anos (idade URBANA) + soma de períodos rurais e urbanos
```

## 2.13 🔴 Direito adquirido × regra de transição

```
   DIREITO ADQUIRIDO .... já CUMPRIU os requisitos até 13/11/2019
                          → lei antiga INTEIRA, inclusive o cálculo
                          → "a qualquer tempo"
   TRANSIÇÃO ............ já era FILIADO, mas não cumpriu os requisitos
                          → escolhe entre as 5 regras
```

# PARTE 5 — PROTOCOLO PARA CASOS PRÁTICOS DE BENEFÍCIOS

```
   ① QUAL BENEFÍCIO? ........ identifique o fato gerador
                              (doença · morte · prisão · parto · idade · sequela)

   ② QUEM PEDE? ............. segurado ou dependente?
                              se dependente → aplique as 3 classes (M11)

   ③ TEM QUALIDADE? ......... aplique o art. 15 (M13)
                              exceção: aposentadorias programáveis (Lei 10.666)

   ④ CUMPRIU CARÊNCIA? ...... 12 · 180 · 10 · 24 · ou 0
                              cheque as dispensas do art. 26

   ⑤ QUAL O MARCO TEMPORAL? . filiou-se antes ou depois de 13/11/2019?
                              já tinha direito adquirido?

   ⑥ QUANTO VALE? ........... 60%+2pp · 91% · 50% · 100% ·
                              50%+10pp/dependente · cota fixa

   ⑦ POR QUANTO TEMPO? ...... duração da pensão · alta programada ·
                              mensalidade de recuperação

   ⑧ ACUMULA? ............... art. 124 + redutor da EC 103

   ⑨ RELEIA O COMANDO ....... "correta" ou "incorreta"? Caçe as palavras-alarme.
```
